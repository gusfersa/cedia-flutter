# ExploraEC — prácticas CEDIA MOD3

Proyecto de formación en Flutter y Dart. Primera etapa: práctica de Sesión 2, widgets básicos y avanzados.
Referencia académica: https://github.com/Patricio-CEDIA/exploraec-app/tree/sesion-02

Estado inicial: preparación local. Publicación en GitHub y entrega Moodle pendientes de aprobación concreta.

Comandos previstos: `flutter pub get`, `flutter analyze`, `flutter test`, `dart run lib/playground/dart_basics.dart`, `flutter run -d chrome`.

La aplicación usa lugares de demostración sin datos privados. No incluye credenciales del aula.
